## SWF Player

An SWF Player backed by Ruffle.

## What It Could Run:

It could run **any SWF**, like Super Mario 63 and other Flash games. Ruffle works a lot better for running Flash files, but it's compatibility is still 82%. For example, tests of Scratch 2.0 runs in Ruffle, though the color is off since it is still in beta.

## What It Could Run Else:

While it is compatible with SWFs, you can insert files. For example, Scratch 2.0 could support files like:

- .sb or .sb2 files

## No Need For UserScripts

You don't need userscripts and Tampermonkey just to get a single SWF to work, when you already have an browser-based Ruffle SWF player created by myself. Scratch works absolutely perfect here, despite it's black. So yeah, use it!
